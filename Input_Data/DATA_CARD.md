# Data card
All architecture, handbook, pattern and question files are original synthetic educational examples generated for this project. No OEM data, personal information, copyrighted standards clauses or vehicle telemetry are included. These files have not been validated by an automotive cybersecurity expert.

The evaluation questions and expected citations were authored from the same handbook, so results measure small-corpus retrieval behavior, not general automotive competence. The challenge split contains paraphrases but is not an independent benchmark. Threat-pattern matching is limited to supplied tags and patterns. Architecture JSON is authoritative; text/PDF uploads extend retrieval knowledge but are not automatically converted into a validated architecture.
