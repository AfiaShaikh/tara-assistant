# Demonstration video

TARA_Demo.mp4 is an automated, captioned, step-based walkthrough of the actual local browser application. It is silent (no voice track), 5 minutes 20 seconds long, and uses synthetic data. Captions describe the implementation and its limitations. It is not a student presentation or proof of optional Ollama/PostgreSQL execution.

The accompanying DEMO_SCRIPT.md supports a student-narrated 5-10 minute recording if required. The 16 original UI screenshots are in Evaluation_Results/screenshots. Browser workflow checks are in Evaluation_Results/browser_check.json.

The recording utility uses Playwright/Chromium; FFmpeg encodes the captured frames. These authoring dependencies are not required to run the application or play the video.
