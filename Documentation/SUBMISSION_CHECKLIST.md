# Final submission checklist

- [x] Runnable local application and source code
- [x] Synthetic input data and knowledge base with provenance
- [x] Prompt, retrieval, risk and model configuration files
- [x] Reproducible tests, ground-truth questions, real baseline metrics and failure examples
- [x] Technical PDF report in a provisional academic format
- [x] Synopsis and faculty approval record prepared for printing
- [x] Student declaration and contribution/dependency disclosure template
- [x] Timed demo script and automated captioned offline walkthrough
- [x] Required folder structure and ZIP packaging utility
- [ ] Fill student names, PRNs, division, guide and individual contributions
- [x] Apply the provided report and synopsis templates
- [ ] Obtain genuine faculty approval and student signatures
- [ ] If pretrained AI is mandatory: install model, record actual digest, run evaluate_llm.py, review outputs, update report/video
- [ ] If presenting PostgreSQL/Docker: validate that deployment and record versions
- [ ] Re-run the submitted package on the evaluation machine
- [ ] Record student narration if required by faculty
- [ ] Regenerate the ZIP after final edits

The checked boxes reflect supplied artifacts and tested baseline behavior, not academic approval or production readiness.
